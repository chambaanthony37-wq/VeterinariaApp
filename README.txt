VETERINARIA APP - JavaFX + FXML + MySQL
Ejemplo intencionalmente SIN MVC y SIN arquitectura por capas.
1. Ejecute veterinaria_db.sql en MySQL.
2. Abra VeterinariaController.java y cambie USUARIO y CLAVE según su MySQL.
3. Abra el proyecto Maven en IntelliJ IDEA, NetBeans o Eclipse.
4. Ejecute: mvn javafx:run
Funciones: listar, guardar, actualizar y eliminar mascotas.
